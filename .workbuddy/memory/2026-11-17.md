# 2026-11-17

## iOS / GitHub Actions 项目初始化
- 目标：在 GitHub Actions 的 macOS runner + iOS Simulator 中运行 SwiftUI iOS App。
- 从官方 `https://github.com/argmaxinc/whisperkit.git` 克隆 Argmax OSS SDK（WhisperKit/SpeakerKit/TTSKit），HEAD `9f99b5c`，MIT。
- 采用官方 SwiftUI demo `Examples/WhisperAX/WhisperAX.xcodeproj`（scheme `WhisperAX`，iOS deployment target 17.0），含 `WhisperAXTests` 与 `WhisperAXUITests`。
- 新增 `.github/workflows/ios-whisperax.yml`：`macos-15` + Xcode 16.4 + `platform=iOS Simulator,OS=18.5,name=iPhone 16`，执行 build-for-testing、unit tests、UI tests 并上传 `.xcresult`。
- 关键点：仓库 SwiftPM `Package.resolved` 为 v3，Xcode 15.2 无法解析；CI 固定 16.4 可解析。模拟器构建传 `CODE_SIGNING_ALLOWED=NO`，无需开发者账号。
- 注意：WhisperAX 默认 encoder/decoder 计算单元为 `.cpuAndNeuralEngine`；模拟器上不能代表真实 NPU 性能，真实 Neural Engine 基准需真机。
